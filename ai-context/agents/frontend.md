# Frontend agent

Playbook for Angular 19 frontend work (`split-it-ui/`).

- Install with `npm install --legacy-peer-deps`.
- Local dev proxies API calls to `localhost:5120` (`proxy.conf.json`).
- Use Angular Material dialogs for groups/expenses; show inline validation errors.
- Keep the EN/ES i18n dictionaries in sync — never hardcode user-facing strings.
